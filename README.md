# Расписание МГТУ для KDE Plasma 6

Виджет рабочего стола для группы **АПИб-24-1, подгруппа 1**. Другую группу можно указать в настройках.

## Возможности

- При открытии показывает пары на сегодня: время, предмет, вид занятия, аудиторию и преподавателя.
- Кнопка «Вся неделя» раскрывает семь дней. Стрелки переключают календарные недели, кнопка «Текущая» возвращает к текущей.
- Чётная и нечётная недели автоматически чередуются. Воскресенье отображается без занятий, если его нет на сайте.
- Расписание загружается с https://timetable.magtu.ru/ при запуске и каждый час; есть ручное обновление.
- Последняя успешная загрузка сохраняется в настройках Plasma. При ошибке сети отображается сохранённая версия с датой обновления. После изменения группы старое расписание не подставляется.

## Установка

Нужны KDE Plasma **6** и `kpackagetool6` (название пакета зависит от дистрибутива). Из каталога проекта:

```sh
kpackagetool6 --type Plasma/Applet --install package
```

Затем: правый клик по рабочему столу → режим редактирования → добавить виджеты → **Расписание МГТУ**. Размер карточки можно менять средствами Plasma.

Обновление установленной версии:

```sh
kpackagetool6 --type Plasma/Applet --upgrade package
```

После обновления удалите виджет с рабочего стола и добавьте снова, чтобы Plasma перечитала QML. Если доступен `plasmawindowed`, отдельное окно можно открыть командой:

```sh
plasmawindowed ru.magtu.timetable
```

Удаление:

```sh
kpackagetool6 --type Plasma/Applet --remove ru.magtu.timetable
```

## Откуда берутся данные

Источник: https://timetable.magtu.ru/АПИб-24-1_1 . Виджет читает только HTML, скрипты и аналитику сайта не запускает. Прокси, сервер, Python или Node.js для работы виджета не нужны.

Парсер привязан к текущей разметке сайта (`day-1-*`, `day-2-*`, `less group-*`). Неполные страницы и неожиданный формат пары вызывают ошибку и не заменяют кэш. При изменениях сайта парсер может потребовать обновления.

В `js/Global.js` сайта МГТУ отсчёт недель привязан к **19 августа 2024**. Виджет считает эту неделю нечётной и переключает чётность по понедельникам, используя локальную дату компьютера. Это соответствует чередованию сайта, но устраняет зависимость от часа суток и переходов часового пояса при расчёте разницы дат. Если вуз поменяет порядок, в настройках можно включить «Поменять чётную и нечётную недели местами».

Просмотр будущих и прошлых недель применяет один из двух повторяющихся шаблонов. Архив расписаний, каникулы и разовые переносы автоматически не определяются. Время и день берутся из часового пояса компьютера — для учёбы в Магнитогорске настройте соответствующий часовой пояс.

## Разработка и проверка

- `package/metadata.json` — метаданные пакета Plasma 6.
- `package/contents/ui/` — интерфейс и страница настроек на QML.
- `package/contents/code/schedule.js` — разбор HTML и календарная логика.
- `tests/fixtures/timetable.html` — сокращённая HTML-копия реального расписания, полученная 28.10.2026 для проверки без сети.

Для тестов нужен Node.js:

```sh
node tests/schedule.test.cjs
TZ=Asia/Yekaterinburg node tests/schedule.test.cjs
TZ=America/New_York node tests/schedule.test.cjs
```

Это первая версия: парсер и календарная логика проверяются отдельно. Запуск QML и внешний вид нужно проверить в сеансе Plasma 6; в среде разработки этого проекта Plasma и инструменты Qt не установлены.
